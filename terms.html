이용약관

대상: 버터핑 자동 업로드 도구 (Google Cloud 프로젝트 “auto-shorts”) · 시행일: 2026년 10월 10일

1. 도구의 성격

버터핑 자동 업로드 도구(이하 “도구”)는 채널 운영자 본인이 만든 사회 지식 쇼츠를 운영자 본인의 유튜브 채널(버터핑)에 올리기 위한 개인용 프로그램입니다. 외부 사용자에게 제공하거나 판매하지 않으며, 가입이나 로그인 기능이 없습니다.

2. YouTube API 서비스

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, 데이터 처리에는 Google 개인정보처리방침이 적용됩니다. 도구는 YouTube API 서비스 약관과 개발자 정책을 따릅니다.

3. 허용된 사용

  • 운영자 본인 채널에 직접 만든 영상을 올리고, 같은 채널의 재생목록에 넣는 용도로만 씁니다.
  • 다른 사람의 채널이나 계정에 접근하지 않습니다.
  • 시청자 데이터, 댓글, 구독자 정보를 모으거나 분석하지 않습니다.

4. 콘텐츠

영상의 대본, 음성, 도식은 운영자가 만들거나 생성한 것이며, 배경으로 쓰는 스톡 영상은 해당 서비스(Pixabay, Pexels)의 라이선스를 따르고 설명란에 출처를 밝힙니다. 영상 내용은 교육 목적의 일반적인 설명이며 법률·투자 자문이 아닙니다.

5. 개인정보

개인정보와 Google 사용자 데이터의 처리는 개인정보처리방침을 따릅니다.

6. 변경과 문의

약관이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 문의는 GitHub 이슈로 남겨 주세요.
