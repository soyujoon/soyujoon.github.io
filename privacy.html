개인정보처리방침

대상: 버터핑 자동 업로드 도구 (Google Cloud 프로젝트 “auto-shorts”) · 시행일: 2026년 10월 10일

1. 이 도구는 무엇인가요

버터핑 자동 업로드 도구는 채널 운영자가 직접 만든 사회 지식 쇼츠를 운영자 본인의 유튜브 채널(버터핑)에 올리기 위한 개인용 도구입니다. 일반 사용자가 가입하거나 로그인하는 서비스가 아니며, 운영자 이외의 사람의 계정이나 정보에는 접근하지 않습니다.

2. 사용하는 Google 사용자 데이터

이 도구는 운영자가 Google OAuth로 직접 허용한 권한(YouTube Data API의 youtube 범위)만 사용하며, 다음 일에만 씁니다.

  • 운영자 채널에 동영상 올리기 (제목, 설명, 태그, 공개 설정 포함)
  • 운영자 채널의 재생목록을 조회하고, 과목별 재생목록을 만들고, 올린 영상을 재생목록에 넣기

시청자 정보, 댓글, 구독자 목록, 시청 기록, 연락처 등 다른 데이터는 읽거나 모으지 않습니다.

3. 보관과 보호

  • OAuth 인증 정보(리프레시 토큰 등)는 GitHub Actions의 암호화된 Secrets에만 보관하며, 공개 저장소나 로그에 기록하지 않습니다.
  • 업로드 기록으로는 영상 주제, 제목, 동영상 ID, 업로드 시각만 남깁니다.
  • Google 사용자 데이터를 판매하거나, 광고에 쓰거나, 제3자와 공유하지 않습니다.

4. Google API 정책 준수

이 도구가 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

이 도구는 YouTube API 서비스를 사용합니다. 관련 내용은 YouTube 서비스 약관과 Google 개인정보처리방침을 참고하세요.

5. 보관 기간과 삭제

  • 업로드 기록(주제, 제목, 동영상 ID, 업로드 시각)은 같은 주제를 두 번 올리지 않기 위해 보관하며, 운영자가 원하면 언제든 지웁니다.
  • OAuth 인증 정보는 도구를 쓰는 동안만 보관합니다. 권한을 철회하거나 도구 사용을 멈추면 GitHub Secrets에서 즉시 삭제합니다.
  • 권한을 철회한 뒤 이미 받은 YouTube API 데이터가 남아 있다면 7일 안에 삭제합니다.
  • 삭제 요청은 아래 문의 경로로 할 수 있습니다.

6. 권한 철회

운영자는 언제든지 Google 계정의 서드 파티 연결 관리에서 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 도구는 더 이상 채널에 접근할 수 없습니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다. 문의는 GitHub 이슈로 남겨 주세요.

Privacy Policy

Applies to: Butterping auto-upload tool (Google Cloud project “auto-shorts”) · Effective October 10, 2026

What this tool is

A personal tool used by the channel owner to upload their own social-studies Shorts to their own YouTube channel (Butterping). It is not a public service; no other users sign in, and it accesses no one else's account or data.

Google user data we use

Only the permission the owner granted through Google OAuth (the YouTube Data API youtube scope), used solely to upload videos to the owner's channel and to list, create and add videos to the owner's playlists. No viewer data, comments, subscriber lists, watch history or contacts are read or collected.

Storage and sharing

OAuth credentials are kept only in encrypted GitHub Actions secrets. The upload log keeps topic, title, video ID and upload time. Google user data is never sold, used for advertising, or shared with third parties.

Google API policies

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Retention and deletion

The upload log is kept only to avoid uploading the same topic twice and can be deleted at any time. OAuth credentials are kept only while the tool is in use and are deleted from GitHub Secrets as soon as access is revoked or the tool is retired. Any YouTube API data still held after access is revoked is deleted within 7 days. Deletion requests can be made through the contact below.

Revoking access

Access can be revoked at any time at Google Account third-party connections.

Changes and contact

Changes are posted on this page with a new effective date. Contact via GitHub issues.
